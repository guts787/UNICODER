Just a quick tool I hacked together for a personal project, feel free to use.
Its a software that can decode and encode hex codes with an animation function for decoding.
Functions:
-Delay - A changeable animation speed.
-Frame skip / Align shift - use these if your matrix stream is shifted or broken to align bytes manually.
-Standard LSB / Reverse MSB - toggles for swapping formats
-Animation Encoding - Encoding multiple pngs to one hex animation.
Requires pillow and pywinstyles to run source. Compiled setup download is available in releases on the right.
